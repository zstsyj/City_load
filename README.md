# 城市电力负荷分析与预测

《Python 数据分析编程》课程项目 · 题目四

## 数据

`data/题4_城市电力负荷.csv`：2017 年全年 10 分钟采样，52,416 行 × 9 列。

| 列名 | 含义 | 单位 |
|---|---|---|
| DateTime | 时间（月/日/年 时:分） | — |
| T | 温度 | °C |
| RH | 相对湿度 | % |
| WS | 风速 | — |
| GDF | general diffuse flows | — |
| DF | diffuse flows | — |
| Z1 / Z2 / Z3 | 三个分区电力负荷 | kW |

无缺失值、无重复时间戳，10 分钟网格完整（2017-01-01 00:00 至 2017-12-30 23:50，共 364 天）。
